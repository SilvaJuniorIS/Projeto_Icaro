Resumo

O Icaro ajuda equipes de compras publicas a parametrizar uma pesquisa de mercado: o usuario informa uma lista de itens, o sistema busca contratacoes publicadas no PNCP, salva resultados como rascunhos de fonte e consolida uma cesta de precos com origem rastreavel.

Principais recursos

  • Cadastro individual ou importacao real de itens via CSV/XLSX.
  • Busca PNCP por termo, periodo, UF e modalidade.
  • Rascunhos PNCP antes da conversao em fonte aproveitada.
  • Revisao final por item com pendencias e status.
  • Relatorios em DOCX, HTML, Markdown e XLSX.

Fluxo de uso

  1. Crie uma pesquisa de mercado.
  2. Importe ou cadastre a cesta de itens.
  3. Busque referencias no PNCP.
  4. Converta rascunhos em fontes com valor unitario revisado.
  5. Revise os itens e exporte o relatorio.

Execucao local

python -m venv venv
venv\Scripts\pip install -r requirements.txt
venv\Scripts\uvicorn api:app --host 127.0.0.1 --port 8100

Acesse http://127.0.0.1:8100 para o dashboard, /landing para a landing page e /github-page para esta pagina modelo.
