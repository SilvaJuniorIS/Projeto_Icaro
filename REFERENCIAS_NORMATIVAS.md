# Referencias normativas iniciais

Este documento registra a base normativa inicial do Projeto Icaro. Ele nao substitui parecer juridico nem a regulamentacao especifica do ente contratante.

## Lei nº 14.133/2021

Fonte oficial: https://www.planalto.gov.br/ccivil_03/_ato2019-2022/2021/lei/l14133.htm

Ponto central para o Icaro:

- O art. 23 trata da estimativa de valor da contratacao.
- O valor estimado deve ser compativel com valores praticados pelo mercado.
- Devem ser considerados bancos de dados publicos, quantidades, economia de escala e peculiaridades do local de execucao.
- Para bens e servicos em geral, a lei admite parametros combinados ou nao, como painel de precos, contratacoes similares, pesquisa em midia especializada/sitios eletronicos e pesquisa direta com fornecedores.

## IN SEGES/ME nº 65/2021

Fonte oficial: https://www.gov.br/compras/pt-br/acesso-a-informacao/legislacao/instrucoes-normativas/instrucao-normativa-seges-me-no-65-de-julho-de-2021

Pontos centrais:

- Formalizacao minima da pesquisa de precos.
- Descricao do objeto.
- Identificacao dos responsaveis pela pesquisa.
- Caracterizacao das fontes consultadas.
- Serie de precos coletados.
- Metodo estatistico aplicado.
- Justificativa para metodologia e para descarte de valores inconsistentes, inexequiveis ou excessivos.
- Memoria de calculo e documentos de suporte.
- Observacao de condicoes comerciais, como prazo, local de entrega, quantidade, pagamento, frete, garantia, marca e modelo quando aplicavel.

## Decreto nº 11.462/2023

Fonte de referencia oficial indicada pelo Governo Federal/DOU; regulamenta o sistema de registro de precos no ambito federal.

Pontos centrais para o Icaro:

- Registro de precos.
- Ata de registro de precos.
- Orgao gerenciador.
- Orgao participante.
- Regras para adesao por orgao nao participante, quando aplicavel.
- Necessidade de comprovar compatibilidade dos precos registrados com valores de mercado.

## Premissas de compliance do Icaro

1. Toda evidencia coletada deve preservar fonte, data e hora de acesso quando aplicavel.
2. A pesquisa deve permitir multiplas fontes.
3. O sistema deve explicar o metodo de calculo adotado.
4. O sistema deve registrar por que uma fonte foi aceita ou descartada.
5. A ferramenta deve apoiar a decisao administrativa, nao substituir a analise juridica, tecnica ou de controle interno.
